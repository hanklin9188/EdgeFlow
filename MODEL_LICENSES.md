| Ministral 3 8B Instruct 2512 GGUF | Apache-2.0 | Public registry entry |
| Qwen3.5 4B | Apache-2.0 | Public registry entry |
| SmolLM2 360M Instruct | Apache-2.0 | Public registry entry |
| Llama 3.2 3B Instruct | Llama 3.2 Community License | Gated; user acceptance required |

The authoritative repositories, exact revisions, gating status, and intended backend support are in `specs/model_registry.yaml`. EdgeFlow does not relicense, mirror, or bundle those weights.
