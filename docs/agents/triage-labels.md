# Triage Labels

Recommended canonical issue states:

| Role | Label | Meaning |
|---|---|---|
| Intake | `needs-triage` | Scope, owner, blocker, or evidence requirement is unresolved |
| Clarification | `needs-info` | External information or a human decision is required |
| Agent work | `ready-for-agent` | Acceptance criteria and blockers are complete |
| Human work | `ready-for-human` | Requires GPU access, legal acceptance, usability participant, or physical environment |
| Closed by decision | `wontfix` | Explicitly declined with rationale |

Suggested domain labels:

- `area:measurement`
- `area:runtime`
- `area:validation`
- `area:policy`
- `area:profiling`
- `area:kernel`
- `area:ui`
- `type:experiment`
- `type:engineering`
- `type:architecture`
- `evidence:blocking`
