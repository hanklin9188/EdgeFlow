# Primary-Source Research Notes

Use this directory for version-sensitive facts that influence experiment design or runtime behavior.

Each note must contain:

1. Question.
2. Pinned software version or commit.
3. Primary sources only: official documentation, source code, specification, or first-party API.
4. Verified facts with citations.
5. EdgeFlow design implications.
6. Assumptions that still require local experiments.
7. Review date and staleness trigger.

Research notes inform hypotheses and configuration choices. They never substitute for EdgeFlow measurements on the target hardware.
